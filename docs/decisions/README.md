# Architecture Decision Records

Important technical decisions should be recorded in this folder.

Use sequential filenames:

- `0001-use-nextjs.md`
- `0002-use-cloudflare-workers.md`
- `0003-use-sanity-cms.md`

Each decision should include:

1. Status
2. Context
3. Decision
4. Alternatives considered
5. Consequences
6. Date
