# Reviewed organization manifests

Place only editor-reviewed organization JSON manifests in this directory. The
importer discovers JSON files non-recursively; this README is ignored.

Copy `../templates/organization-template.json`, replace the placeholders with
source-supported facts, register the source in `../source-registry.json`, and
follow `../../../docs/approved-data-owner-guide.md`.

Never create an organization from an ambiguous organizer label.
