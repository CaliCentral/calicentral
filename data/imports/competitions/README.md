# Reviewed competition manifests

Place only editor-reviewed competition JSON manifests in this directory. The
importer discovers JSON files non-recursively; this README is ignored.

The versioned contract, source-only and provider-backed examples, validation
commands, source-rights gate, and mutation safeguards are documented in
[`../../../docs/reviewed-competition-import.md`](../../../docs/reviewed-competition-import.md).

Do not copy ranking manifests into this directory, and do not fabricate a
provider competition ID when a source publishes none. Use a stable
`reviewedKey` for a source-only record instead.
